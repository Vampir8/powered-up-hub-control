# Web panel screenshot

`powered-up-hub-control-panel.png` shows the English web panel included in this
repository, with its dark canvas and demonstration configuration/state.

The example shows nControl connected to the ESP32, two Train nodes, two Powered
Up hubs, and a motor plus lights assigned to each hub. Unused slots are hidden
and the canvas is fitted to show the connections.

Battery percentages and connection states are sample values. The IP address is
a documentation example. No real credentials or device addresses are included.
No physical output is operated to produce the screenshot.
