# Web panel screenshot

`powered-up-hub-control-panel.jpg` is a browser screenshot of the actual English
web panel included in this repository, using demonstration configuration and state.

The example shows nControl connected to the ESP32, one Train assigned to two
Powered Up hubs, and a motor plus lights attached to each hub. Unused Train and
hub nodes are hidden and the canvas is fitted to show the connections.

Battery percentages and connected states are sample values, not a live hardware
test. The displayed IP address is a documentation example. No real credentials
or device addresses are included. The screenshot is not AI-generated.
